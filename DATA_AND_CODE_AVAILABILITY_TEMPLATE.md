## Open Research / Data and Code Availability

The analysis-ready data, source register, variable dictionary, standalone analysis code, Figure 3–9 plotting code and data, and machine-readable quality-control records used in this study are publicly available in the GitHub repository Not All Gallons Are Equal: Analysis Reproducibility Package, version 1.0.0, at https://github.com/amobiamanambu/not-all-gallons-are-equal. The repository is released under the licensing and reuse conditions specified within the archive. The archive is limited to records used in the manuscript: 97 named Google location-years, 70 U.S. Meta facility-years, four matched U.S. AWS regions, the 26-location U.S. Aqueduct screen, 32,874 daily observations from three USGS stations, the Mesa records used to construct the quality-controlled daily and monthly pathways, and four Quincy reuse evidence records. Primary reports and datasets are cited directly in the manuscript tables, figure captions, and reference list. Large provider reports and the complete Aqueduct 4.0 distribution remain available from their publishers and are not redistributed. The repository preserves the published Google FY2024 aggregate inconsistency as a documented source issue and excludes that aggregate row from named-location consumption results rather than silently correcting it.

This repository address should also be included in the manuscript’s Open Research section.
